# Digital Clock PCB Design ⏱️

I am thrilled to share my latest PCB design project! 🚀

I recently designed a complete Digital Clock board from scratch using **Altium Designer**. This project was a fantastic opportunity to apply core digital electronics concepts and level up my schematic and PCB layout skills.

## 📌 Key Technical Details
* Utilized an **LM555 Timer** for clock pulse generation.
* Implemented TTL Logic ICs, specifically **74LS90** (Decade Counters) and **74LS47** (BCD to 7-Segment Decoders), to drive the digital logic.
* Designed the display interface using six **7-Segment Displays**.
* Integrated a **USB Type-C** port for a modern and reliable power supply.
* Focused heavily on optimized component placement and clean routing on both layers to ensure circuit efficiency and signal integrity.
